# Tomato Metronome

A simple metronome application with a Pomodoro timer integrated into one utility.

## Features

- **Metronome**: Adjustable tempo (BPM) with visual and audio cues
- **Pomodoro Timer**: 25-minute work sessions with customizable intervals (To be implemented)

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/tomato-metronome.git
   cd tomato-metronome
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm start
   ```
